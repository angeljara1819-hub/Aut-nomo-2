📝 Cómo usar
1. Ejecuta el programa

2. Selecciona la longitud de la contraseña (ej: 12 caracteres)

3. Elige los tipos de caracteres que quieres incluir

4. Haz clic en "Generar Contraseña"

5. Copia la contraseña con el botón "Copiar al portapapeles"

🤝 Contribuir
Si quieres mejorar este proyecto:

1. Haz fork del repositorio

2. Crea una rama: git checkout -b nueva-funcionalidad

3. Haz commit de tus cambios: git commit -m 'Añado X funcionalidad'

4. Haz push: git push origin nueva-funcionalidad

5. Abre un Pull Request
